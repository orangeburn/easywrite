# 情绪裁决法｜v0.2

> 定位：把读者**原本就有的态度、反感、争议或切身困扰**，转化为作者可以论证的鲜明叙事立场。既可用于发现切入角度，也可用于选定角度后的标题、封面及表达检查；不替作者决定选题，不承诺点击效果。需要研究依据或结果复核涉及情绪与点击的外推时，按需阅读 [Reference](../references/verdict-evidence.md)。

## 核心任务

从作者已经给出的原始判断中，找到一个目标读者熟悉、且**在作者表达之前就已存在情绪或争议**的对象、行为或处境；再提炼一句作者愿意承担论证责任的裁决。

“裁决”可以是对一项事实、行为、行业模式、趋势或群体遭遇作出清晰判断，**不是越狠越好**。不需要同时存在两派：读者对无效会议的共同厌恶，也可能比两方辩论更适合这一表达方式。

可能的点击前假设：读者辨认对象 → 既有态度被触动 → 想确认、反驳或看作者如何论证。但这不是已经验证的完整因果模型；读者也可能反感过激表达或根本不认识对象。

## 使用步骤（作者明确要求找角度，或已经指定裁决式表达时）

1. **从原始观点抽取判断**。先找作者真的表达过什么、想批评或维护什么；不把作者的谨慎观点强化成他没有说过的绝对结论。
2. **找熟悉的具体对象与处境**。区分读者认识某个品牌、产品、行业概念，和读者亲自经历某类工作困扰。优先呈现一个能够指认的行为或事件，不靠“资本”“时代”“行业”这类空泛抽象名词维持冲突。
3. **查作者表达之前的态度基础**。寻找真实的公开争论、当事人说法、时间线、投诉、经验或读者反馈；区分小社群、行业受众和公众，不能凭一两个评论断言群体普遍愤怒。**作者的文章引发的评论，不证明写作之前就有相同情绪**。
4. **找到真正要判定的一件事**。针对具体行为、规则、交付结果、模式或趋势写一句可争辩的判断；明确其成立范围。分别辨认事实陈述（发生了什么）、价值判断（是否值得）、预测（未来可能怎样），不要把后两者写成已证实事实。
5. **探索裁决的叙事入口**。读者点击前更容易认出的是什么：被批评的对象、他自己承担的代价，还是作者判下的结论？尝试改变主语或具体动作，但不要只做同一句话的情绪强度梯度。
6. **作者选角度后再做标题与封面**。标题可以点明对象，也可以在热点、账号语境与封面能补足对象时短句裁决。封面尽量呈现发生的动作或判断背后的机制；隐喻可以抽象，不能使未经证实的故事看起来像现场照片。
7. **交还作者**。提供可选的裁决切口、对应原始观点、既有态度证据及需要兑现的关键论据；不据此推断这一路径点击率优于其他方法。

## 检查结果时使用

**裁决是否有内容**：它究竟判定了哪个可识别的对象或行为？有没有明确适用范围、事实基础、论证责任？若去掉贬义词只剩普通事实，裁决可能没有新判断。

**情绪是否真的先存在**：读者属于什么群体？有什么发表前证据？缺乏基础时可以保留为“作者表达立场”，不能声称触发已有集体情绪。

**点击前表达是否可辨认**：只看到标题与封面，读者是否知道在批评什么；是否可能产生认同或反驳的理由？标题是否越过证据、把预测写成事实、或对目标读者本人进行不必要的攻击？

**研究外推是否过度**：不能因为有负面词汇增加点击的实验，就宣称强烈裁决、愤怒或争议必然带来流量。若输出出现这类推论，按需查 [Reference](../references/verdict-evidence.md)，但不自动向用户展示研究综述。

## 与其他方法的关系

认知反转关注修正已有解释；裁决关注作者针对熟悉对象给出的态度和判断。异常解谜关注为什么出现某种结果；裁决不必留下原因悬念。利益揭示可帮助找到被忽略的承担者，裁决可用来表达对其遭遇的态度。荒诞现场可把裁决所针对的行为变成具体可感的画面。

## 退出或改用其他方法

没有可识别对象，既有态度只来自模型臆测，作者判断缺乏相应依据，或只能靠夸张、攻击读者、预言式断言维持标题冲突：不要包装为已成立的裁决角度。可以降级为作者的待论证立场或改用其他方法。

## 交付要点

**作者原始判断 → 具体对象及已存在的读者态度 → 一句有范围的裁决 → 可尝试的点击前切口 → 正文必须兑现的证据／最大反证**。作者选择后再进入组织文章与标题封面。
