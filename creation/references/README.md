# Creation references 使用约定

本目录存放**辅助资料**，不承担 Creation 的入口路由，也不直接规定文章怎么写。执行规则以 [Creation 入口](../SKILL.md) 和对应的 [methods](../methods/) 为准。

## 目录内容与触发条件

| 文件 | 内容 | 何时读取 | 不适用场景 |
| --- | --- | --- | --- |
| [reversal-evidence.md](./reversal-evidence.md) | 认知反转相关研究、原始来源与外推限制 | 明确要求解释/检验认知反转法的理论基础，或修订该方法规则时 | 日常从观点池找角度、给标题、推断某选题是否有点击率 |
| [notion-original.md](./notion-original.md) | 创建 GitHub Skill 时的 Notion 原文快照 | 追溯历史版本、核对迁移内容时 | 当作最新指令，覆盖 `SKILL.md` 或 `methods/` |

## 读取原则

1. **先判任务，再决定是否需要参考。** 普通选题、文章大纲、标题封面任务，不需要读取学术研究笔记。只读入口、实际触发的方法及本次选题的有效来源。
2. **就事读文件，不做全目录预加载。** 用户询问方法有效性或要求修订方法时，才读取对应理论资料；同一问题无关的参考文档不读取。
3. **参考资料不替代方法规则。** 文献可以支持或反驳一个机制，不能直接证明我们定义的整个方法有效；研究和方法矛盾时应指出并修订方法，而不是假装研究已经验证了它。
4. **参考资料不替代事件核查。** 真实人物、品牌、行业共识、社会情绪、成本数据和新闻事件都要为该选题另外查证；老论文或历史案例不能证明当下读者一定存在某种态度。
5. **不默认向作者展示资料。** 创作输出只保留与当前任务有关的事实、候选和不确定性；用户问依据时才解释相关文献。

未来可以增设案例、数据和视觉参考文件，但必须写明用途、触发条件和失效边界。
