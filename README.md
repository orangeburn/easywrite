# EasyWrite

面向中文文章的 AI 写作 Skill，支持观点探索、文章创作、内容审阅，以及口播和演讲稿转写。

通过一个入口描述任务，EasyWrite 会根据材料和目标选择相应工作流。

## 功能

| 工作流 | 适用任务 | 主要输出 |
| --- | --- | --- |
| [创作](./creation/WORKFLOW.md) | 从观点寻找切入角度，组织或修改文章，设计标题与封面创意 | 候选角度、大纲、正文、局部修改稿、标题与封面方案 |
| [审阅](./review/WORKFLOW.md) | 检查大纲、正文片段或全文，评估发布准备情况 | 有原文依据的问题、影响说明和修改建议 |
| [转写](./rewrite/README.md) | 将完整文章适配为音频或现场表达，检查已有转写稿 | 口播稿、提词器稿、现场演讲稿，以及与原文的对应检查 |

创作包含情绪裁决、认知反转、异常解谜、利益揭示和荒诞现场五种角度探索方法。审阅使用[完整写作审查框架](./review/framework.md)，关注读者理解、观点与论证、结构、表达、传播及发布风险，并按文章目标评估商业价值。

转写保留原文的事实、观点、条件、判断力度和作者声音，调整信息顺序与表达方式，以适应收听或演讲场景。

## 安装

将本仓库的完整目录放入所用 AI 客户端支持的 Skill 目录，保留根目录 [SKILL.md](./SKILL.md) 及其子目录。具体安装路径和启用方式以客户端说明为准。

EasyWrite 的 Skill 名称为 `easywrite`。支持显式 Skill 调用的客户端可使用 `$easywrite`；自然语言调用也可使用“用 ew”。

## 使用示例

调用时提供要处理的材料，并说明任务和范围：

```text
用 easywrite 从以下观点中寻找文章切入角度。
用 ew 检查下面这份大纲的逻辑和结构。
用 ew 为这篇文章设计标题与封面创意。
用 ew 修改下面这段文字，保留原有观点，压缩重复表达。
用 ew 审阅这篇完整文章，判断是否适合发布。
用 ew 把这篇文章转成可以直接朗读的播客稿。
用 ew 把这篇文章转成适合现场演讲的稿子。
用 ew 对照原文检查这份口播稿是否遗漏或改变了意思。
```

已有角度、大纲或正文时，可以直接从相应阶段继续。创作时由作者选择切入角度；审阅可以聚焦某个维度，也可以覆盖全文。可以在一次请求中指定多个步骤，也可以逐步推进。

## 转写方式

- **[TTS 口播稿](./rewrite/renderers/tts/WORKFLOW.md)**：提供完整措辞，适合直接朗读、播客录制、视频旁白或语音合成。
- **[Speech 表达稿](./rewrite/renderers/speech/WORKFLOW.md)**：提供允许演讲者自然调整措辞的表达结构，包含提词器和现场演讲两种模式。

生成和核对转写稿需要完整原文。EasyWrite 交付文稿与创意方案，实际语音合成和图片生成需配合相应工具。
